# Third-party notices and data services

PCSS includes npm dependencies whose license metadata is recorded in
`package-lock.json`. Direct runtime dependencies React and React DOM are MIT
licensed. Development dependencies include software under permissive licenses,
including MIT and Apache-2.0. Their original license texts and notices remain
available in their respective distributions.

PCSS interoperates with, but does not bundle or operate, these public services:

- [PubChem PUG REST](https://pubchem.ncbi.nlm.nih.gov/docs/pug-rest)
- [EMBL-EBI UniChem](https://www.ebi.ac.uk/unichem/)
- [ChEBI](https://www.ebi.ac.uk/chebi/)
- [ChEMBL](https://www.ebi.ac.uk/chembl/)
