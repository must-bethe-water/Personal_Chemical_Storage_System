# Support

Use the GitHub issue forms for reproducible bugs and focused feature requests.
Before reporting a bug, install the latest release and check existing issues.
Include the PCSS version, macOS version, Mac architecture, network state, and
minimal reproduction steps.

Never upload a real inventory, backup, API key, Apple certificate, or other
sensitive laboratory data. Follow [SECURITY.md](SECURITY.md) for vulnerabilities.

PCSS is maintained by volunteers. There is no guaranteed response time,
service-level agreement, or emergency chemical-safety support.
